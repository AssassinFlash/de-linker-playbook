# Looker Studio 看板搭建指南

本指南给操作者亲手搭「De-linker 运营看板」。目标是一屏看清：L0–L3 反馈、动作进度、最近执行登记、页面收录和搜索表现。看板只读「底表」；它不写回数据，也不替代 AI 的「下一步」判断。

> 本票只验收核心看板。网页表现与搜索词现在可以为空；等 GSC 出数后，由「看板表现面板补验」单独核验。

## 开始前

### 你要看懂的三件事

1. **一个 Google Sheets 数据源只连一个工作表。** 所以「执行登记」「网页表现」等工作表要分别添加成数据源。
2. **不要写死行数或 A1:U68 这类范围。** 选择工作表标签，让连接器随底表自动扩行。
3. **时区不同。** 执行登记、动作进度、询盘等时刻是北京时间；「网页表现」和「搜索词」的日期按 Google 的太平洋时间切日。

- 表格真实链接和 ID 只在私有 vault `deliverables/marketing/00-system/base-table.md` 里查看；不要写进公开文档或截图。

- 不放密钥；服务账号密钥、IMAP 密码、Woo 密钥都不进 Looker Studio。

## 第 1 步：创建空报表

**这一步在干什么：** 先建一个由 `所有者账号` 拥有的空报表，后面所有数据源和版面都放在这里。

1. 用电脑浏览器登录 `所有者账号`。
2. 打开私有 vault `deliverables/marketing/00-system/base-table.md`，找到「底表」链接；只复制到浏览器标签页备用，不要截图这个 vault 页面。
3. 打开 <https://datastudio.google.com/>。
4. 依次点 **Create / 创建** → **Report / 报表** → **Blank / 空白**。
5. 报表命名为 **De-linker 运营看板**。

**截图位 1：** 报表名称出现在画布顶部；截图时避开账号头像和地址栏。

## 第 2 步：添加 6 个数据源

**这一步在干什么：** Looker Studio 的 Google Sheets 连接器一次只连一张工作表。把看板需要的 6 张数据表分别接进来。

依次添加以下工作表，数据源名称保持和工作表名完全一致：

1. `执行登记`
2. `网页收录`
3. `网页表现`
4. `搜索词`
5. `询盘`
6. `动作进度`

每添加一张，都按同一套动作做：

1. 在报表编辑器里打开 **Add data / 添加数据**。
2. 选择 **Create new data source / 创建新数据源**。
3. 选择 **Google Sheets** 连接器，授权使用 `所有者账号`。
4. 选中「底表」这本表格。
5. **Worksheet / 工作表** 选择上表中的一张工作表标签；不要改用自定义范围。
6. 确认 **Use first row as headers / 首行作为表头** 已勾选。
7. 点 **Connect / 连接**，再点 **Add to report / 添加到报表**。
8. 回到资源面板，把数据源名称改成该工作表名。

**截图位 2：** 六个数据源名称在资源面板中排成一列；不要截到底表链接或 ID。

## 第 3 步：检查字段类型

**这一步在干什么：** 字段类型错了，日期趋势、去重计数和汇总都会失效。这里只改 Looker 的字段解释，不改 Google 表格。

在 `动作进度` 数据源里创建一个计算字段：

| 字段名 | 公式 | 用途 |
| --- | --- | --- |
| `动作数` | `COUNT_DISTINCT(登记编号)` | L0–L3 scorecard |

在 `询盘` 数据源里创建：

| 字段名 | 公式 | 用途 |
| --- | --- | --- |
| `询盘数` | `COUNT_DISTINCT(询盘内部编号)` | 询盘总数 |

再逐个数据源检查类型：

| 字段 | 类型 |
| --- | --- |
| `执行日期`、`检查日期`、`日期（太平洋时间）` | Date / 日期 |
| `登记时刻（北京时间）`、`写入时刻（北京时间）`、`更新时刻（北京时间）` | Date & Time / 日期时间 |
| `展示`、`点击`、`近 7 天展示`、`近 7 天点击` | Number / 数字，聚合 SUM |
| `点击率`、`平均排名` | Number / 数字 |
| `登记编号`、`网址`、`搜索词`、`国家`、`设备`、`搜索类型` | Text / 文本 |
| `询盘内部编号` | Number / 数字，仅用于去重 |

**截图位 3：** `动作数` 与 `询盘数` 字段已创建，类型为 Number。

## 第 4 步：搭第一屏「今日总览」

**这一步在干什么：** 第一屏回答“现在做了多少、走到哪一级、最近发生了什么”。

把页面命名为 **今日总览**。顶部放标题文字：`De-linker 运营看板 · 今日总览`。标题下放一行说明：`L0 已执行 → L1 已到达 → L2 有互动 → L3 有转化；询盘只含形式发票申请。`

### 4.1 五个数字卡

用 **Scorecard** 添加 5 张数字卡，横向排一行：

| 数字卡 | 数据源 | 指标 | 过滤条件 | 标题 |
| --- | --- | --- | --- | --- |
| 1 | `动作进度` | `动作数` | 无 | `L0 已执行动作` |
| 2 | `动作进度` | `动作数` | `当前最高级别` 属于 `L1`、`L2`、`L3` | `已到达 L1` |
| 3 | `动作进度` | `动作数` | `当前最高级别` 属于 `L2`、`L3` | `已互动 L2` |
| 4 | `动作进度` | `动作数` | `当前最高级别` 为 `L3` | `已转化 L3` |
| 5 | `询盘` | `询盘数` | 无 | `形式发票询盘总数` |

这些 L1/L2/L3 是累计口径：一个动作到了 L2，也会被算进“已到达 L1”。在每个数字卡下面加一行小字：`L1/L2/L3 为累计口径`。

**截图位 4：** 五张数字卡在同一行，数字和标题清楚可读。

### 4.2 动作进度表

**这一步在干什么：** 让你一眼看到每个动作现在走到哪一级。

添加一个 **Table / 表格**：

- 数据源：`动作进度`
- 维度：`执行日期`、`登记编号`、`线`、`渠道`、`动作大类`、`动作`、`网址或收件公司`
- 维度继续放：`查证结果`、`当前最高级别`、`收录状态`、`和上次比`
- 指标：`近 7 天展示`、`近 7 天点击`、`归因询盘数`
- 排序：`执行日期` 倒序；第二排序 `登记编号` 倒序
- 行数 / 分页：每页 20 行
- 标题：`动作进度（最新 20 条）`

**截图位 5：** 动作进度表在第一屏下半部，不用横向滚动也能看到 `当前最高级别` 和 `收录状态`。

### 4.3 最近执行登记

**这一步在干什么：** 每天先确认最近一次动作是什么，作为归因锚点。

再添加一个表格：

- 数据源：`执行登记`
- 维度：`登记时刻（北京时间）`、`登记编号`、`线`、`渠道`、`动作大类`、`动作`、`内容说明`、`网址`、`收件公司`、`查证结果`
- 不要放：`邮件 Message-ID`、`查证证据`、`备注`
- 排序：`登记时刻（北京时间）` 倒序
- 行数：5 行
- 标题：`最近 5 条执行登记`

**截图位 6：** 最近执行登记表显示 5 行，操作者能直接读出最近一次动作。

### 第一屏自检

- [ ] 能说出 L0–L3 的数字。
- [ ] 能说出形式发票询盘总数。
- [ ] `动作进度` 一屏可见，不用先点进第二页。
- [ ] 最近 5 条执行登记能直接看到。
- [ ] 第一屏没有表格 ID、Message-ID 或密钥。

## 第 5 步：搭第二屏「趋势与页面」

**这一步在干什么：** 第二屏看搜索表现和每个页面的收录 / 展示 / 点击状态。

新增页面，命名为 **趋势与页面**。顶部标题：`趋势与页面 · GSC 数据`，副标题：`网页表现与搜索词按太平洋时间切日；空图表示 Google 尚未出数。`

### 5.1 添加筛选控件

**这一步在干什么：** 让你按国家、设备、搜索类型拆开看，不把不同维度混在一起。

在页面顶部放 4 个控件：

| 控件 | 字段 | 类型 |
| --- | --- | --- |
| 日期 | `日期（太平洋时间）` | Date range / 日期范围 |
| 国家 | `国家` | Drop-down list / 下拉列表 |
| 设备 | `设备` | Drop-down list / 下拉列表 |
| 搜索类型 | `搜索类型` | Drop-down list / 下拉列表 |

选中这 4 个控件和本页后面的趋势图、页面表、搜索词表，使用 **Group / 分组** 或官方的 “apply controls to specific charts” 功能，让它们只影响第二屏的图表，不影响第一屏。

日期控件先用 **Auto / 自动**。国家、设备、搜索类型保持可多选；现在没有数据也照样保留控件，数据到了直接生效。

**截图位 7：** 四个控件在页面顶部，并且能看到它们与第二屏图表在同一分组。

### 5.2 搜索表现趋势

**这一步在干什么：** 看展示和点击随日期的变化。

添加 **Time series / 时间序列**：

- 数据源：`网页表现`
- 日期维度：`日期（太平洋时间）`
- 指标：`展示` 聚合 SUM；`点击` 聚合 SUM
- 不筛选国家、设备或搜索类型；交给上方控件
- 标题：`搜索表现趋势（按太平洋日期）`
- 图例：保留“展示”“点击”

当前这张图可以为空。不要用假数据填充，也不要删掉它。

**截图位 8：** 空的时间序列图仍在页面上，标题和字段设置可见。

### 5.3 页面收录与表现表

**这一步在干什么：** 把最新收录状态和累计搜索表现放到同一行，逐个页面检查。

先创建一个 blend，命名为 **页面收录与表现**：

1. 打开 **Resource / 资源** → **Manage blends / 管理 blend** → 新建。
2. 表 A 选 `网页收录`，重命名为 `收录状态`：
   - 维度：`网址`、`收录状态`
   - 指标：`检查日期`，聚合设为 MAX，显示名改成 `最新检查日期`
3. 表 B 选 `网页表现`，重命名为 `搜索表现`：
   - 维度：`网址`
   - 指标：`展示` SUM；`点击` SUM
4. Join 字段：左边 `网址` = 右边 `网址`。
5. Join 类型选 **Left outer / 左连接**，以收录状态为主，保留尚无表现的页面。
6. 保存 blend。

用这个 blend 添加表格：

- 维度：`网址`、`收录状态`
- 指标：`最新检查日期`、`展示`、`点击`
- 排序：`最新检查日期` 倒序，第二排序 `展示` 倒序
- 标题：`页面收录与表现（按网址与状态汇总）`

如果某个网址历史上从“未收录”变成“已收录”，表里可能出现两行状态。读数规则写在表格旁：**看 `最新检查日期` 最大的那行，就是当前状态。**

**截图位 9：** 页面表的字段面板或表格标题，能看到 blend 名称和左连接设置。

### 5.4 搜索词面板

**这一步在干什么：** 有搜索数据后，看哪些词带来展示和点击。

添加表格：

- 数据源：`搜索词`
- 维度：`搜索词`、`网址`、`搜索类型`、`国家`、`设备`
- 指标：`展示` SUM、`点击` SUM、`点击率`、`平均排名`
- 排序：`展示` 倒序；第二排序 `点击` 倒序
- 分页：每页 100 行
- 标题：`搜索词（等 GSC 出数）`

当前可以为空。保留数据源、字段和排序；不要写死行数。

**截图位 10：** 空的搜索词表仍在页面上。

### 5.5 留位面板

**这一步在干什么：** 给后续回流留明确位置，避免以后重排版面。

在第二屏底部放三个文本框：

1. `L3 版面扩展位：询盘明细与归因，等待「询盘回流 L3」。`
2. `邮件反馈版面留位：送达、退信、回复，等待「邮箱 IMAP 回流」。`
3. `GA4 版面留位：访问、来源、着陆页；仅统计同意分析的访客，无建模补齐，不能与 GSC 点击直接对账。`

**截图位 11：** 三个留位文本在第二屏底部，GA4 文案包含“仅统计同意分析的访客”。

## 第 6 步：刷新数据

**这一步在干什么：** 底表每天由脚本更新；看板要重新取数。

1. 打开报表的查看或编辑页。
2. 点 **Refresh / 刷新** 报表数据。
3. 如果刚刷新过，等至少 1 分钟再刷新；官方冷却时间是 1 分钟。
4. 只有底表新增或修改了列时，才需要到数据源里刷新字段；日常新增行不需要改字段。

**截图位 12：** 刷新按钮位置；不要截出账号信息。

## 常见卡点

| 卡点 | 怎么处理 |
| --- | --- |
| 找不到底表 | 只回私有 vault `deliverables/marketing/00-system/base-table.md` 找链接；不要问公开文档。 |
| 数据源里没有中文表头 | 确认选的是正确工作表，并勾选“首行作为表头”。 |
| 数字卡没有去重 | 使用 `COUNT_DISTINCT(登记编号)` / `COUNT_DISTINCT(询盘内部编号)`，不要用普通 COUNT。 |
| 日期不能做趋势 | 回到数据源，把日期字段类型改为 Date。 |
| 网页表现 / 搜索词为空 | 正常；Google 尚未出数。保留面板，等「看板表现面板补验」。 |
| 筛选控件影响了第一屏 | 选中控件和第二屏图表重新分组，确认第一屏不在同一控件作用范围。 |
| 页面表一个网址多行 | 这是按 `网址 × 收录状态` 聚合；看 `最新检查日期` 最大的行。 |
| 截图里出现表格 ID 或邮箱 | 重新裁剪或打码后再交给 agent。 |
| 照指南仍无法走通 | 停在卡住的那一步，把步骤编号、屏幕现象和截图位编号告诉 agent；不要自行换成自建看板。 |
