# 每日提醒

每天早上，电脑自动跑两条回流写进底表：GSC（从 Google 取搜索与收录）和询盘（从网站取形式发票申请）。两条都跑完，接着按反馈规则算出当天的「下一步」，送到三个地方：

| 送到哪 | 看到什么 |
| --- | --- |
| Mac「提醒事项」App，列表「de-linker 下一步」 | 一条提醒。标题就是当天要做的那件事，点开看「备注」是全文 |
| `日常账号` 的邮箱 | 一封信，主题是「de-linker 下一步 · 日期：要做的事」，正文和提醒备注一样 |
| 工作邮箱 `chester@de-linker.com` | 同一封信，留作工作记录 |

真实邮箱地址只写在仓外的配置文件和私有 vault 里，本页只写角色名。

## 什么时候到

- 08:30 开始取数。先跑 GSC 回流，再跑询盘回流，再导出本地看板 JSON。GSC 在网址多的日子要 40 分钟左右；当天已经查过的网址不会重查。询盘回流和看板导出见 `docs/base-table.md`。
- 两条回流都跑完，或其中一条失败，紧接着算「下一步」并送出（算一次大约 40 秒）。看板导出失败不改变提醒措辞，但会让这次定时的退出码不为 0。所以提醒一般在 09:10 前后到。
- Mac 当时在睡眠：醒来后补跑。关机的那天没有提醒。

## 提醒里写什么

提醒用大白话写，只有三块（操作者 2026-10-15 定：太长、太机械的部分不要，报错代码不要）：

1. **下一步**：标题就是今天要做的那件事。正文先用一两句话说为什么，再写「怎么做」，一步一步写到点哪个按钮；要用到的网址列在下面。不用你做的事，会写明「这件不用你做」。
2. **之后还有**：最多 5 件，一件一行；AI 自己会做的，后面标「（不用你做）」。
3. **网站现在**：一句话，比如 Google 收录了多少页、**内容页**最近一周被搜到几次、点进来几次、询盘一共几条。法律页（Impressum、Datenschutz、条款）的展示不算进去；首页算内容页。口径与验收一致。

规则编号、优先级、表名、台账阶段这些都不写进提醒。想看完整版（带依据和编号），开个对话跟 AI 说「下一步」。

几种特殊的日子：

| 标题 | 意思 |
| --- | --- |
| 下一步：今天没有要你做的事 | 网站和邮件都在正常等反馈 |
| 今天取数没成功｜下一步：…… | 今天取数失败：GSC 或询盘有一条没成功，就用这个提醒。「下一步」按上次取到的数据算。原因 AI 下次对话时会查，你不用管 |
| 今天没算出下一步 | 算的时候出了问题（多半是网络或表格连不上）。开个对话跟 AI 说「下一步」，AI 会再算一次 |

出错的细节只写进日志，不发给你。

前一天自动建的提醒，如果你还没勾掉，第二天会被自动勾掉，因为当天的新提醒已经取代了它；没做完的事会在新提醒里再出现。你自己在这个列表里手动加的提醒不会被动。

## 看状态、关掉、重装

在「终端」里，进到本仓库目录后：

```sh
uv run scripts/gsc_pull.py schedule status    # 定时装没装、上次退出码、日志最后几行
uv run scripts/gsc_pull.py schedule remove    # 关掉：取数和提醒一起停
uv run scripts/gsc_pull.py schedule install   # 重新装上（每天 08:30；先 GSC，再询盘，再提醒。需先配好 Woo 只读密钥）
uv run scripts/daily_reminder.py run --dry-run   # 只把今天的提醒打印出来看，不送
uv run scripts/next_step.py --format plain       # 同样的大白话版「下一步」
```

日志在 `~/Library/Logs/de-linker-playbook/gsc-pull.log`：GSC、询盘回流和提醒写在同一个定时日志里，提醒的行以「每日提醒：」开头。上次退出码不是 0，说明 GSC、询盘、提醒里有一样出了问题，日志里写着是哪一样。GSC 或询盘任一失败，提醒都按「今天取数没成功」送出。这些是给 AI 查原因用的，你不用看。

## 用到的配置（都在两个仓库之外）

- `~/.config/de-linker-playbook/config.toml` 的 `[reminder]` 段：收件人、发信服务器、发信账号、授权码文件在哪。
- `~/.config/de-linker-playbook/qq-smtp-auth-code`：QQ 邮箱的授权码（权限 600）。要换授权码：在 QQ 邮箱「账号与安全 → 安全设置 → 授权码管理」删掉旧的、生成新的，用文本编辑把新码存到这个文件、覆盖旧的。
- 「提醒事项」的授权：第一次运行时 macOS 弹框，点了「好」。在「系统设置 → 隐私与安全性 → 自动化」里能看到、也能收回。
