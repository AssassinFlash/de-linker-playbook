# 看板表现面板补验

## Question

（HITL）看板先验收核心后，「近 7 天展示 / 点击」这一项留在这里：等「GSC 数据回流」出数并关票后，操作者打开看板，确认网页表现与搜索词的面板真的显示数据、数字与底表对得上。

## 由来（「Looker Studio 看板」2026-10-19 拆分时写入）

- 看板票为了让核心先验收，把 GSC 表现部分的验收拆出，等数据到了再做。看板票的完成标准与拆分理由见 `tickets/looker-dashboard.md`。
- 前置数据：网页表现、搜索词两张表在 2026-10-19 仍是 0 行（Google 尚未出任何展示）；「GSC 数据回流」的完成标准要求「至少一个页面的收录状态与近 7 天展示」，所以本票挂在它后面。

## 怎么做

1. 等「GSC 数据回流」关票（底表网页表现表出现真实行）。
2. 操作者打开看板（链接在私有 vault `marketing/00-system/base-table.md` 同目录的看板记录；本仓库不写链接）。看两处：
   - 第二屏「展示 / 点击」：近 7 天有非零数字，日期范围能在底表对上。
   - 「搜索词」面板（若看板已放）：有真实词，不是空白或报错。
3. 数字与底表对不上或面板空白：查数据源范围是否按整列取、日期字段类型是否正确（网页表现与搜索词是太平洋时间）；修完再看。
4. 记下证据：截图或操作者口述的具体数字，写进 Resolution。

## 完成标准

- 操作者能看着看板说出近 7 天展示 / 点击的一个具体数字，且与底表一致。
- 搜索词面板有数（看板放了这块时）；没放则记一句「未放搜索词面板」。
