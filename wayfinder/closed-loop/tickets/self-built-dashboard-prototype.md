## Question

三套结构放在同一页，用 `?variant=` 切换。结构必须不同，不是换颜色：

- A 双栏运营台：侧栏 + 数字 + 不合并列的表。最接近那套模板。
- B 一封早报：没有侧栏，没有卡片。整页是一段今天怎样。
- C 先拆开再看：没有侧栏。先选国家 / 设备 / 搜索类型，再看阶梯。数字不会变，因为底表还拆不开。

Google 数据以后仍由每天 08:30 的回流链写入底表。这页不连表，也不做浏览器到表格的代理。
