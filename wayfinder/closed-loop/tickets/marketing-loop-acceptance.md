# 营销线闭环验收

## Question

（HITL）用真实动作走一遍营销线：操作者发布或更新一个真实页面 / 内容 → 口述 → AI 查证并写执行登记 → 等数据（GSC 晚 2–3 天）→ 底表与看板上出现该页的 L1（收录 / 展示）及以上 → 操作者说「下一步」→ AI 引用这条数据给出一个动作；同一条数据也出现在当天早上的每日提醒里（「提醒事项」和邮件）。

- 失败的环节当轮修（在对应 skill / 脚本里），不记 backlog；修不了的切新票并在本图登记。
- 记录全链证据（执行登记编号、底表行、看板截图、「下一步」原话）到 vault 的成品记录；公开仓库只记「通过 / 不通过 + 环节」。

## 完成标准

- 一条执行登记能沿链追到底表反馈、看板呈现、AI 下一步，且下一步可回溯到「反馈分级规则定稿」的某条规则。
