# Looker Studio 看板

## Question

（HITL：操作者按指南动手做，agent 写指南、核对成品）建看板，接底表，让操作者每天一屏看清「现在怎样」（裁定 Q8、Q9）。

- Looker Studio 报表无成熟写入 API〔以官方文档复核〕，所以是**操作者亲手搭、agent 写逐步图文指南**——这同时是操作者的学习材料。指南放 `docs/`（公开，只写角色名，不含表格 ID），一步一截图位 / 一步一句「这一步在干什么」。
- 看板内容（Q9）：L0–L3 各级数字与趋势；每个已上线页面的收录 / 展示 / 点击状态；最近执行登记。本票先做 L0–L2（GSC）；L3、邮件、GA4 的版面先留位置，由「询盘回流 L3」「邮箱 IMAP 回流」「GA4 进看板」各自补。
- 可另接 GSC 原生连接器作对照，但主数据源是底表（执行登记归因只在底表里）。
- 共享：`所有者账号` 所有，`日常账号` 编辑。链接记 vault。
- 若 Looker Studio 对初学者确实走不通（指南写完、操作者照做仍卡住），按 Notes「自建看板是后备」就地切新票，不在本票硬做。

## 完成标准

- 操作者独立打开看板，能口头说出：哪些页已收录、近 7 天展示 / 点击、最近一次执行登记是什么。

## 交接

- 看板结构与「补版面」的方法，写进「询盘回流 L3」「邮箱 IMAP 回流」「GA4 进看板」三票正文。
