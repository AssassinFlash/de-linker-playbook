# Structure 12 专业帖骨架

条件：起草或质检市场准入专业帖时读本文。执行顺序与完成条件以 `SKILL.md` 为准。篇幅、钩子种类、CTA 种类、标签组合、四种风格升级与软广，以 `skills/lead-generation/references/linkedin-post-guidelines.md` 为准，不把该文件正文抄进交付物。

## 五拍（编号固定，不可增删、不可换序）

1. **Hook** — 点名专业领域 + 目标区域。折叠前必须能读出「哪条准入规则 / 哪段流程 × 哪个市场」。
2. **Knowledge / Tip / Process** — 一条可执行的具体知识、步骤或本公司真实流程。读者按此能核对或能少走一步错路。
3. **Company Simplification** — 经验、团队或服务如何让买家更快、更稳、少补件。必须能回溯产品上下文或用户本轮；不能回溯则不得写成「我们代办 / 我们已注册」。
4. **Buyer Benefit** — 把流程翻译成该区域买家本地可感到的结果（少滞港、少一次补件、文件一次过审）。不堆内部职能名。
5. **CTA** — 恰好一个，对准该区域买家。种类取共用规范，不另起第五种。

其后：空一行 + 3–5 个标签。本帖型标签须含目标区域；其余按共用规范的宽标签 / 品类 / 话题组合。贸易、出口、合规类话题标签可选用，但不用空洞标签。

## 各拍约束

- Hook 禁止空套开场。区域名必须出现在前 210 字符内。
- Knowledge 禁止停在「我们懂该市场法规」。必须落到可点名的制度、单据、步骤或内部核对点。
- Simplification 最多 1–2 句产品或服务；删掉这两句后，Knowledge + Benefit 仍应独立有用。
- Benefit 必须绑该区域，不写「对全球买家都好」。
- 五拍都写完再加标签。标签不进五拍正文。

## 风格升级

用户点名微博客 / 故事叙事 / 滑梯式 / 直销节奏之一时：先按五拍写成稿，再只改语气与分段，不改专业领域、不改已核验事实、不改区域。未点名则保持本骨架。
