## 五段

顺序固定，不得换段、不得合并 Reality 与 Benefit、不得把 CTA 塞进 Hook。

| 段 | 必须做到 |
| --- | --- |
| Hook | 一句把误区说刺耳，或把对比说成正在做的决定。落在折叠前。 |
| Myth / Comparison | 误区：写清「谁、在什么采购场景、信了什么」。对比：写清两个真实选项与决策条件。 |
| Reality / Expert Analysis | 纠正或下判断；至少绑一条证据（URL 或产品上下文）。 |
| Buyer Benefit | 该 ICP 可感到的结果，不是「现在你知道了」。 |
| CTA | 恰好一个，类型见共用规范。不承诺未有材料。 |

其后 3–5 个标签，组合规则见共用规范。品类标签取产品上下文的品类字段，不在本文填值。

## 分帧

**myth（揭穿）**

- 对象是错误信念，不是买家本人。
- 先承认该信念为何看起来合理，再拆。
- 拆完仍要给可执行的改法（要哪份证书、问哪句规格、按哪项总成本比），否则只是打脸。

**comparison（对比）**

- 两边都是市场上有人会选的真实做法。
- 每边至少一条利、一条代价，接到该 ICP 的交期、规格、总成本或风险。
- 结论写成「在条件 C 下选 A」，不是「永远选 A」。

选 `myth` 当且仅当搜索摘录里有人把该说法当成事实。选 `comparison` 当且仅当两边都有真实代价。对不上就换候选，不硬套。

## 证据

至少一条，优先可核验、可被该 ICP 复核：

- 技术规格或检测结果（已抓取页或产品上下文）
- 行业标准或认证名称（上下文确有，或公开标准页）
- 公开行业报告中的数字（URL + 年份）
- 产品上下文里的项目/来料观察（不编客户名）
- 带单位的成本或交期对比（上下文或已抓取页）

没有以上任何一类 → 该帖 Reality 未完成，标缺口，不把个人观点写成「事实是」。

禁止：无出处百分比、未持有的认证、点名竞品的「他们都掺假」、把模型记忆当标准号。

## Buyer Benefit

把 Reality 翻成该 ICP 的决策结果。能勾上其中一条才算写完：

- 少一次来料不合格或规格返工
- 少付不该付的运费、加急费或索赔
- 一次写对规格 / MOQ / 交期假设
- 在两个真实选项里选对，而不是事后补救

写不出具体结果 → 选定的误区或对比对该 ICP 可能不成立，换候选。

## 查询模板

花括号是字段，取产品上下文与已批准 ICP，不把花括号句抄进交付物。够用即停，不为凑次数加查。

误区是否存在：

```
"{product_niche}" common misconceptions buyers
"{product_niche}" myths sourcing {target_market}
"{product_niche}" "hidden cost" OR "true cost" buyers
```

证据：

```
"{product_niche}" quality standards comparison
"{product_niche}" {standard_or_spec} site:.org OR filetype:pdf
"{option_a}" vs "{option_b}" {product_niche} lead time OR cost
```

公开讨论（证明有人这么说，不是证明你对）：

```
"{product_niche}" myth OR misconception OR "truth about"
"{product_niche}" "which is better" {option_a} {option_b}
```

有用：摘录里出现目标买家、该说法或该对比，且来源可追溯。噪声：软文标题党、与品类无关的消费口碑。
