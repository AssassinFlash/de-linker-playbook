# 报价策略（Smart Pricing + Outcome Framing）

按已读产品上下文与可核验公开价，为当前买家写双语（EN 与 CN）结果导向报价策略，落到 `deliverables/lead/10-sales/`。缺价格、毛利锚或可核验承诺则标缺口，不编造。

## 步骤

1. **共用规则**。读 `skills/marketing-playbook-standards/SKILL.md`。完成：能复述数据锚定、例子禁引用、产出根、工具写能力。
2. **输入**。产品与公司事实读事实源入口 `docs/fact-sources.md`，按其「什么问题查哪个源」取证；查不到标〔未证实〕，按没有处理。原文不拷进本仓库。存在则再读：`deliverables/lead/10-sales/first-contact.md`、`deliverables/lead/01-icp/icp-analysis.md`、`deliverables/lead/04-market/` 下市场或竞品稿、`deliverables/lead/05-usp/` 下 USP 或产品知识、`deliverables/marketing/01-foundation/` 下定价稿。不在本文件另开访谈剧本。从上下文、本轮、上游凑齐五参：报价产品（名称/规格/变体）、买家类型、买家国家或地区、MOQ 与交期、预判的买家侧顾虑。编排上本 skill 在 `lead-service-first-contact` 批准之后（见 `skills/lead-generation/SKILL.md` 阶段 10）；用户直接点名报价时仍执行，缺失首触稿则标缺口，不伪造已建立的对话基调。产品或买家类型仍缺：打开 `skills/lead-interview/SKILL.md`（存在则按其做）；不存在则停并写缺口。完成：五参齐或已标缺口；产品与买家类型已锁定，否则未写策略。
3. **查证**。用网页搜索查证两类意图：品类 × 买家国的批发/进口价格带；该买家类型在该市场的转售毛利预期。需要原文时抓取指定 URL。需要隔离第二国或第二买家类型时 dispatch a subagent, else do it inline。搜索不可用：结构仍写，所有市场数字标缺口，不编造基准价或毛利。完成：有搜索日志；引用的价带、毛利、运费或关税能回溯 URL 与访问日期，或已标缺口。
4. **设计五件套**。只用已收集事实套「写法」：Smart Pricing Structure、Embedded Value Offers、Trust Clause、Outcome Framing、Reorder Logic。单价与折扣只来自产品上下文、本轮或已抓取页；买家毛利只在有转售/零售锚时计算。完成：五件套草稿均能回溯来源或已标缺口；未用教学句子填空。
5. **落盘** `deliverables/lead/10-sales/quotation-strategy.md`。完成：文件非空；「产出」断言全过或对应缺口已写；教学支架原文零出现。

## 写法

报价是一场关于利润与风险的对话，不是一张单价表。只报单价会把买家推向比价；写出单位成本下降、风险下降、长期便利，才把话题从「多便宜」转到「多赚钱」。

**Smart Pricing。** 默认三档，上下文另有断点则用上下文：MOQ 基础档、2×MOQ 走量档、5×MOQ 或回头单合作档。每档写清：本司单价、相对基础档的单位成本下降、断点理由（对买家的信号）。有转售价或公开零售锚才算买家毛利；没有则毛利标缺口，不编造零售价。电商转售、批发、品牌方、经销商不共用同一套毛利假设。

**Embedded Value Offers。** 只从上下文确有的能力里抽低成本、高感知、并绑在续单上的附加：改包装、样品费冲抵、品质处置、上市辅助。每条标注能力来源、供应商成本（有则写，无则缺口）、买家感知价值（有公开替代成本才写金额）、与续单的关系。目标 3 条；能力不够则列缺口，不拿虚构质检或摄影凑数。

**Trust Clause。** 定价表下方一句双语。降低与新供应商合作的感知风险；含可核验的过程、时限或验证方式；该承诺能回溯上下文或已抓取页。空话（保证质量、我们负责）不写。上下文没有可核验承诺则整句标缺口，不编造抽检项数或补发时限。

**Outcome Framing。** 用买家语言写三块：sell-through（产品如何帮对方卖得动）、风险下降（条款如何降低对方暴露）、毛利优化（对方如何多赚，而不只是少花）。与该国相关的运费、关税、清关必须进入框架或标缺口。有数字的句子必须能回溯来源。

**Reorder Logic。** 用结构便利鼓励回头，不像合同陷阱。从下列类型里选与该买家匹配的，目标 2 条：SKU 对齐对方内部编码、按年重置的累计返点、库存触发的备货、共享订单台账（表格或看板）、共创包装成为对方品牌资产。每条写做法、对买家的便利、实施时间线。切换成本是副作用，不是目的。

## 例子

> 仅供理解，禁止引用到输出。

输入已有产品、买家类型、目标国、MOQ、交货术语。阶梯写成 MOQ / 2×MOQ / 5×MOQ 三档（上下文另有断点则用上下文），并解释断点信号。上下文没有转售锚就不写买家毛利金额。

输入把有效期写成礼貌说明 → 成稿应改成一口价买方用来挡住自身下游涨价风险的窗口：过期后报价文件可留、单价须重核。不要写无限期有效，也不把锁价天数编成卖点。

输入只给一张总价 → 成稿应改成可摊平行项目：净价、币种、计价单位、带指名地点的交货术语、数量断点、包装假设。不要用「含运」含糊带过。预算询价不要当成正式标来回。

输入只喂单价与交期 → 成稿应同时过商务闸（净价、有效期、付款）和技术闸（对照规格的符合项、随报文件包类型）。只过商务闸会在技术闸卡住。

输入默认写账期净天数 → 成稿应改成新户/出口默认预付加形式发票，账期是账户审批后的特权。没有审批事实就标缺口，不发明净天数或折扣点数。

信任条款只引用上下文里可核验的过程或时限；价值附加只抽上下文确有的能力。不要写自有质保承保、备件库、库存现货或到货日承诺当卖点；质保写清谁出保、谁跑单，不把厂家年数写成己方承诺。不要写「12 项检验、48 小时补发」，也不写「免费产品摄影值 200 美元」除非上下文确有摄影能力且有可核验替代成本。报价只清对方下单前已卡住的商业条件，不种新的选型百科问。

再订货用「谈一次、按需提货」的便利，不要写成换掉现有供应商或合同捆绑。安装商首单按备线开口，不按换商。运费与清关进入 Outcome Framing 或标缺口。不要把本节句子粘进交付物。

## 易错

- 只报单价，没有单位成本下降、风险或毛利框架。
- 无来源地写批发基准、零售价或「行业常见毛利」。
- 把营销树目录价或成本栈当成这一单的报价策略。
- 电商转售与经销商共用同一套毛利假设。
- 信任条款空话，或编造抽检项数、补发时限、第三方报告。
- 用虚构摄影、改包装、质保凑满三条价值附加。
- 再订货机制写成合同捆绑，而不是对方用着方便。
- 忽略该国运费、关税、清关。
- 缺首触稿却伪造已谈妥的语气或已承诺条款。
- 终稿只出一种语言却声称双语完成。
- 把 skill 例子原文写入交付物。
