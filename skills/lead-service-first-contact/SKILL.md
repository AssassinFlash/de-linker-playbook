# 首次联系策略（Market Insight Hook + Lock-In）

为一名已合格买家写一对一、中英对照的首触方案：市场洞察钩子、三句破格消息、差异化标语、像服务的软锁定。落到 `deliverables/lead/10-sales/first-contact.md`。缺证据标缺口，不编造趋势或证明。

## 步骤

1. **共用规则**。读 `skills/marketing-playbook-standards/SKILL.md`。完成：能复述数据锚定、例子禁引用、产出根、工具写能力。

2. **输入**。产品与公司事实读事实源入口 `docs/fact-sources.md`，按其「什么问题查哪个源」取证；查不到标〔未证实〕，按没有处理。硬依赖：已批准的 `deliverables/lead/01-icp/icp-analysis.md` 与 `deliverables/lead/05-usp/usp-strategy.md`。软依赖存在则读：`deliverables/lead/04-market/competitor-positioning.md`。用户本轮给出的买家、市场、通道或竞品弱点记「用户本轮」。四项取值必须齐：所卖产品、买家类型、目标国/地区、竞品常见弱点。材料仍不够清楚时，打开 `skills/lead-interview/SKILL.md`（存在则按其做）；不存在则把缺口写入台账，不在本文件另写问卷。完成：能指出四项各依据哪几条；原文不拷进本仓库。任一硬依赖文件缺失、用户本轮也未给出对应全文、且无 `user_waiver` → 停。本 skill 写销售服务链入口的一对一消息，不写批量开发信（打开 `skills/lead-cold-email-gen/SKILL.md`，文件存在时），不写异议回复或报价稿。

3. **查证**。用网页搜索查证买家所在国 + 品类的进口/渠道趋势，以及该市场买家侧风险或未满足需求。竞品弱点在上游仍薄时，再搜一轮该品类供应商的公开投诉。查询用当前公历年，不写死年份。需要原文则抓取指定 URL。不为「首触话术最佳实践」凑查询，方法在本文件。搜索不可用或搜不到该国该品类的具体数据：Hook 禁止写百分比、研究名或「数据表明」；用已批准痛点或区域级公开趋势，并在缺口写明数据边界。完成：Hook 将用的每条事实能回溯 URL 与访问日期，或已标缺口；搜索日志已记。

4. **起草**。按「写法」写出四个组件，买家可见段必须 EN + CN。软 CTA 与锁定所承诺的材料、看板、报告：必须是已有交付物、产品上下文已有能力、或本轮能立刻写出的短件；做不到的不写进消息，改标「需业务确认」并换可执行项。完成：四件齐全；钩子对应该国该品类；第一句不是工厂介绍或产品参数；可信度句可核验或已标「未在上下文出现」；锁定有执行步骤。

5. **质检并落盘**。对照清单写入 `deliverables/lead/10-sales/first-contact.md`。只产策略与可复制消息，不发送。验证—审查—审批走 `skills/lead-generation/references/orchestration-protocol.md`，本 skill 不代替审批。完成：主文件非空；教学支架原文零出现。下游报价打开 `skills/lead-service-quotation/SKILL.md`（文件存在时）；场景心理打开 `skills/lead-buyer-psychology/SKILL.md`（文件存在时）——本步不执行它们。

## 写法

买家每天收到大量供应商消息。「我们是工厂、做了十年」等于没说。首句必须让对方停下来：用该市场的风险、机会或反直觉公开事实，打断「这是我们的价目表」模式。

- **Market Insight Hook**：一条趋势、买家侧风险或未满足需求。必须对应该国 + 该品类；从买家损益写，不从工厂产能写。有数字必须有来源与年份；无来源不写数字。
- **三句消息**，一句一职，不可合并或扩成段：
  1. 破格：接 Hook，不要产品介绍、工厂历史或「Dear Sir/Madam」。
  2. 可信度：一条可核验事实（检测报告、年限、客户类别、交期、不良率）。空话「high quality / leading」删掉。上下文没有则写「未在上下文出现」，不要用第二句硬撑。
  3. 软 CTA：给对方一份低承诺材料，不索取会议、不逼下单。口吻是「要不要我把 X 给你」，不是「你能不能做 Y」。
- **差异化标语**：一句，直接回输入里的竞品弱点，不另起一套卖点。
- **嵌入式锁定**：选一种可执行的软协作，让切换变贵但读起来像增值，不像合同绑架。类型只从下表取；表里没有的能力不要发明。

| 类型 | 何时可用 |
| --- | --- |
| 共享订单追踪 | 能提供共享表或看板，并写谁更新、多久一次 |
| 联合市场适配 | 能按对方品类做对照或适配短报 |
| 顾问短件 | 能立刻做利润/规格/合规对照（只含已有数字） |
| 包装或品牌协作咨询 | 产品上下文确有包装/贴牌能力 |
| 该区域市场短报 | 本轮已搜到可引用公开来源，能在本轮交稿 |

锁定必须带执行步骤（谁、做什么、何时、对方得到什么）。做不到的标「需业务确认」，另选一行。

- 可信度要具体，不要自称。软 CTA 要给价值，不要要动作。锁定要看不见推销。
- 不同市场不共用同一稿。产地、认证、贸易条款以产品上下文为准，不默认某一出口国或某一电商平台。
- 优先级：Hook 与三句为 P0；锁定能本轮落地为 P0，需对方配合为 P1，可选增值为 P2。标语随 P0。

## 例子

> 仅供理解，禁止引用到输出。

输入写「安装商、让他换供应商」。成稿应把首触写成开一条备线、只动购物篮某一行，而不是换商或发价目表。Hook 落到该国该品类一条可核验风险（到货改口、索赔难、施工季没空谈新供应商），不要工厂介绍。第一句不准以工厂或参数开头。第三句给一份本轮能交出的短材料，不要约电话。锁定写成共享订单追踪或联合适配，并写谁更新、多久一次；不要写「本周锁单」。上下文没有认证或客户数时，第二句写「未在上下文出现」，不要编不良率。

输入写「EPC 采购、把报价和交期甩过去」。成稿应拆双闸：商务闸把报价有效期写成对方一口价合同上的风险工具，不是礼貌期限；技术闸另给文件包或兼容证据，不要只满足谈价的人（技术审批可以否决商务）。Hook 必须落到该国 + 该品类带来源的风险或趋势；没有数字就写「未在来源出现」，不写某季度退货涨了百分之几。标语回应对手交货后失联，不要自称制造商或备件库。本节句子不得进入交付物。

## 易错

- 没读 ICP / USP、没搜该国该品类就发明趋势百分比。
- 把本文件当成 `lead-cold-email-gen` 的批量开发信，或当成异议/报价稿。
- 第一句工厂自我介绍、价目表开场、或「Dear Sir/Madam」。
- 可信度写「best quality」或编造证书、客户名、不良率。
- CTA 约会议、逼下单，或承诺做不到的报告与看板。
- 锁定读起来像陷阱或合同绑架。
- 美 / 欧 / 中东同一稿。
- 只出英文或只出中文。
- 标语不碰竞品弱点。
- 把 skill 例子原文写入交付物。
- 硬依赖缺失且无 `user_waiver` 仍往下做。
