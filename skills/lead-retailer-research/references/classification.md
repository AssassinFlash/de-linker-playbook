# 零售商分类口径

条件：做 SKILL 步骤 4（画像）时读本文。用下列枚举填表，不要把本节表格当某家公司的事实。

## 市场地位 `market_position`

表内只写下列四值之一。审查清单里的 leader / emerging / niche / regional 与此对应。

| 值 | 含义 | 采用时必须有的公开信号（至少 1 条，已搜索或已抓取） |
| --- | --- | --- |
| `market_leader` | 在该细分里体量或心智占优 | 第三方份额/排名、行业奖、同市场内门店或搜索可见度明显高于同表同行 |
| `emerging_player` | 正在扩大份额或网点 | 新店/新市场、融资或扩张报道、可核验的增长叙述（媒体或年报口径） |
| `niche_focus` | 产品或客群收得很窄 | 站点几乎只讲一个子品类或一个客群，而不是全线百货 |
| `regional_specialist` | 强在特定地理 | 多店或口碑集中在一国/一省/一城；站点或报道明确地理范围 |

没有信号就不要打这四个值：该公司不进已核验表，写入缺口，不猜。没听过 ≠ `emerging_player`。站点自称 leader 而没有第三方或可比较的规模信号，不够。

同一家可能又窄又区域：选**更决定其生意**的一个主标签，另一点写进概览，不要两个值塞进 `market_position`。

## 细分聚焦 `niche_focus`

`niche_focus` **列**写可观察的短描述（客群、价位带、用途、材质/风格承诺中能从首页核验的那些）。下面五类只用于 Markdown 分组，不是列里的唯一合法词。

| 分组 | 观察什么 |
| --- | --- |
| `eco-friendly` | 可持续、再生、认证材料等，须能在站点或包装承诺上看到 |
| `premium` | 高价定位、设计师合作、奢侈渠道；最好有可核验价位带 |
| `budget-friendly` | 走量、折扣、入门价；最好有可核验价位带 |
| `age-specific` | 明确年龄或人生阶段客群 |
| `industry-specific` | 服务某一行业买家（酒店、项目、某个工业场景） |

五类都对不上：分组写 `other`，列里仍写具体细分。对得上两类：分组用主类，次类写进概览。

空话不算完成：「各种产品」「高端产品」「他们做零售」。要写成第三人能打开同一页复核的句子。

## 其他字段

- `years_in_business`：在**该品类**经营的年数，不是公司注册年（注册年可写在概览）。来源：关于我们、新闻、注册信息。没有就 `unknown`。
- `primary_customers`：终端消费者、哪类企业客户、或二者；写清谁走进店/站。
- `employee_count`：整数 + `data_source` URL。只有 “small team” 无数字 → 不进已核验表。
- `data_source`：地位、规模、细分所依据的 URL，可分号并列。
