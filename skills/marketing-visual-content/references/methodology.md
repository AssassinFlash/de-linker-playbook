## 输入

先读事实源入口 `docs/fact-sources.md`（台账 `product_context` 即指向它），按其「什么问题查哪个源」取证；查不到标〔未证实〕，按没有处理。上游若已存在则读：

- `deliverables/marketing/03-content/content-strategy.md` — 内容支柱、渠道优先级、编辑日历
- `deliverables/marketing/01-foundation/` — 定位与差异化
- `deliverables/marketing/03-content/` 下已有品牌视觉规则或资产清单

产品事实不写进 skill，不另写公司档案。

### 最小上下文

- 品类：产品上下文的品类字段，不在本文填 SKU
- 目标市场：产品上下文的目标市场字段
- 应用场景：产品上下文已写的安装/使用场景
- 品牌语气与禁用视觉风格（若有）
- 本轮交付：静图、视频、或二者
- 目标渠道：以产品上下文为准
- 资产模式：实拍 / 仅照片 / AI 生成 / 混合
- 出镜：仅产品 / 工艺人员 / 客户 / 发言人 / 无
- 用户已配置的生图或生视频工具

缺产品上下文则停。缺渠道或交付类型时，用产品上下文能辩护的默认并写缺口，不发明第二套渠道。

## 采集

默认一条能力：用 Apify 搜索查证。需要原文时抓取指定 URL 的正文（含动态页）。Apify 修复与替代取证后仍不可得则停止并写缺口，不编造、不并列多引擎菜单。

把产品上下文的品类与目标市场代入下列意图，每条记下 URL、摘录、访问日期：

1. 同品类在目标渠道上的视觉趋势（静图构图、色盘、材质特写）
2. 同品类短视频或 Reels 高表现结构（钩子、时长、CTA）
3. B2B 制造/外贸产品摄影与场景图参考
4. AI 产品摄影提示词结构（画幅、光线、机位）
5. 目标渠道视频脚本框架（B2B 制造）
6. 竞品官网图库、产品页主图、社交或视频频道

补充意图（结果不够时再查，不换工具品牌）：相邻品类视觉、产线过程片、安装现场图。

### 竞品视觉/视频审计

识别 3–5 个同品类竞品图库、社交账号或视频频道。

- 静图：角度、背景、光线、色盘、构图、渠道画幅
- 视频：标题、前 3–5 秒钩子、时长、结构、CTA、可见互动信号、评论主题
- 每条观察必须有 `source` URL 或公开账号句柄

### 按需平台规格

只采集用户本轮或产品上下文点名的渠道。下表是画幅参照，不是默认渠道清单。

| 渠道类型 | 静图画幅 | 视频画幅 | 常见模式 |
| --- | --- | --- | --- |
| 竖图灵感流 | 2:3（约 1000×1500） | 不适用 | 场景向往、材质丰富 |
| 社交方图/竖图 | 1:1 或 4:5 | 9:16 短视频 | 编辑感、品牌一致 |
| 职业社交 | 1.91:1 | 1:1 或 16:9 | 专业、带应用语境 |
| 长视频平台 | 16:9 封面 | 16:9 长片 | 教学/权威或产品展示 |
| 短视频平台 | 9:16 | 9:16 | 钩子先行、快切、原生感 |
| 网站首屏 | 16:9 或 21:9 | 背景循环 | 满幅、氛围 |
| 邮件头图 | 约 600×200 | 不适用 | 干净、单主体 |

### 最低数据量

- ≥50 条视觉趋势参考（图/帖），带来源渠道与约数
- ≥20 张竞品产品图或视频帧，有具体风格笔记
- ≥10 条目标渠道短视频或社交样本
- 3–5 个重复出现的视觉风格，附频次理由
- 视频：≥3 条真实竞品片的钩子/结构拆解
- 静图 prompt：≥5 条能回溯已采集参考的示例结构（写入交付物，不抄 skill 例子）

### 校验

- 每个数字或条数能回溯真实搜索或抓取结果
- 钩子分析必须写清前 3–5 秒看见什么、听见什么
- 风格模式必须落在已采集参考上，不写「行业惯例」
- 竞品内容稀缺时扩到相邻品类，并注明扩围
- 禁止虚构浏览量、互动率或参考 URL

## 分析

### 视觉风格

产出表：风格名、描述、频次证据、最适渠道、示例来源 URL。

常见对照（用采集结果勾选或改名，不把本表当事实）：

| 风格名 | 描述 | 常见去处 |
| --- | --- | --- |
| 棚拍干净 | 中性背景、产品居中、商业摄影 | 网站 / 职业社交 |
| 建筑语境 | 产品装在真实空间 | 灵感流 / 社交 |
| 材质特写 | 表面/纹理微距 | 社交 / 短视频 |
| 编辑灯光 | 深色背景、戏剧光 | 灵感流 / 社交 |
| 工艺过程 | 制造或手作进行中 | 长视频 / 职业社交 |

### 竞品缺口

对每个竞品来源记录：惯用角度（正视 / 3/4 / 特写 / 场景）、主导背景（白棚 / 灰棚 / 实地 / 渲染）、光线（柔光棚 / 戏剧 / 自然 / 轮廓光）、缺失项（缺的角度、场景或画幅 = 差异化机会）。

### 视频框架

若本轮含视频：

1. 按目标选文案模型：销售/直接反应（Agitator、PAS、AIDA）；认知（身份升级、叙事、4P）；教育/权威（Myth Buster、QUEST、清单教学）；产品展示（视觉 ASMR、Secret Hack、SLAP）。
2. 提出 3 个差异化钩子，每个钩子绑一条竞品或趋势来源。
3. 用产品上下文校准语气（权威 / 挑战 / 亲近），附一句样例台词。
4. 逐镜表字段：scene、visual、narration、camera、lighting、sfx、duration、source_reference。

### 生图提示词

结构：

```
[主体] + [风格] + [机位] + [光线] + [场景] + [质量词] + 画幅
```

- 真实感词、材质词、场景词、光线词、情绪词都必须能回溯产品上下文或已采集参考。
- 材质/表面/应用场景：只写产品上下文已有的；缺则标「未在上下文出现」，不编造纹理或产地。
- 画幅写成渠道对应的 `--ar` 或像素，不写「通用方图」。
- 若用户指定需负向提示的工具，负向词用：模糊、低质量、扭曲、卡通、绘画。不把未配置的工具写进推荐。

### 用途映射

| 用途 | 优先渠道类型 | 情绪 | 关键画面 |
| --- | --- | --- | --- |
| 产品主图 | 网站、样本 | 干净、可报价 | 产品居中、中性背景、锐利 |
| 安装/使用场景 | 灵感流、社交 | 可向往 | 真实空间、环境光、语境 |
| 材质细节 | 社交、短视频 | 触感 | 微距、虚化、表面反光 |
| 产线/工艺 | 职业社交、长视频 | 可核验 | 人员、设备、原料（出镜以范围为准） |
| 社交帖配图 | 社交、职业社交 | 品牌一致 | 干净、可读、色盘锁定 |
| 视频封面 | 长视频、职业社交 | 高对比 | 主体清楚、可读字、情绪 |

渠道具体名称以产品上下文为准。

## 交付

### 策略文档

`deliverables/marketing/03-content/visual-content/index.md` 必含：

1. 视觉趋势总览 — top 5 风格，频次证据与来源
2. 竞品视觉/视频分析 — ≥3 家，角度、光线、背景、缺口、source URL
3. 平台视觉策略 — 每个点名渠道的画幅 + 风格，附数据理由
4. 生图/生视频工具选型 — 按用途，只推荐用户已配置或可公开使用的类型
5. Prompt / Script 库概览 — 分类与命名约定
6. 行动建议 — P0 必做 / P1 建议 / P2 可选

每条建议必须同时有：来源渠道、频次或样本数、参考 URL。

文档顶部声明已读 `product_context`（及若存在的内容策略），不粘贴原文。

### 图片 Prompt 库

`deliverables/marketing/03-content/visual-assets/prompt-library.md`

每条形状：

```
**[名称]** — [用途]
Platform: [目标渠道]
AI Tool: [用户已配置的工具类型]
Aspect Ratio: [画幅]
Prompt: [完整提示词]
Style Keywords: [逗号分隔]
Reference: [URL 或「派生自 [渠道] 趋势分析」并指向采集条目]
Notes: [何时用、可变体]
```

≥10 条完整 prompt，每条有 `source` 与画幅。

### 视频脚本包

仅当范围含视频。目录：`deliverables/marketing/03-content/visual-assets/video-scripts/`

- `script-[topic]-[platform].md` — 逐镜（画面、旁白、运镜、灯光、音效、时长、来源）
- `shot-list.md` — 分镜头视觉拆解
- `production-checklist.md` — 拍摄准备
- `ai-visual-prompts.md` — 逐场景生图/生视频 prompt

### 工作簿

从 `templates/visual-style-guide.xlsx` 复制到 `deliverables/marketing/03-content/visual-style-guide.xlsx` 后填行。

**prompt_library**：`prompt_id`、`name`、`use_case`、`platform`、`ai_tool`、`aspect_ratio`、`prompt_text`、`style_keywords`、`source`、`priority`

**visual_trends**：`style_name`、`description`、`frequency_evidence`、`best_platform`、`source_url`

**video_scripts**：`scene_id`、`timecode`、`visual`、`narration`、`camera`、`lighting`、`sfx`、`source_reference`

**competitor_audit**：`competitor`、`source_url`、`angles`、`backgrounds`、`lighting`、`gaps`

每个 sheet 的 `source` / `source_url` / `source_reference` 非空率 ≥95%。未做视频时在 `video_scripts` 首行写原因，其余行不留假数据。

### 执行附件（按需）

写到 `deliverables/marketing/03-content/visual-assets/`：

- `visual-guidelines.md` — 色盘、禁用风格、可/不可
- `platform-specs.md` — 点名渠道的尺寸、格式、安全区
- `competitor-visual-audit.md` — 图库/视频分析与 URL
- `trend-report.md` — 趋势摘要与来源数据

## 反模式

1. 不调研真实趋势就写通用 prompt 或脚本
2. 忽略渠道画幅
3. 风格或钩子没有竞品或趋势来源
4. 编造浏览量、钉图数、互动率或 URL
5. 跳过竞品视觉分析
6. 只给一个钩子或一条 prompt
7. 语气、框架、钩子未确认就写全片
8. 终稿留未解释占位符

## 质量闸门

- 已读 `product_context`；内容策略若存在则已读
- 趋势 / 竞品 / 短视频样本达到上文最低条数，或已写搜索缺口
- Top 5 风格有频次证据
- 每条 prompt 能回溯已采集图、片或趋势来源
- 全部静图与视频标注目标渠道及画幅
- 竞品缺口写成具体缺失的角度、场景或格式
- 视频：3 个钩子带来源；逐镜含画面、旁白、运镜、灯光、音效、时长、来源
- 工作簿每个 sheet 有 `source` 列
- 无 `[insert image here]`、`[待补充]`

## 可验证断言

交付物文末写 5–10 条，形状如下（按本轮实际勾选，不抄未做的项）：

1. `visual-content/index.md` 存在且含全部 6 个必选节
2. Prompt 库 ≥10 条完整 prompt，每条有 `source` 与 `aspect_ratio`
3. 竞品审计 ≥3 家，每家含 source URL、angles、backgrounds、lighting、gaps
4. 趋势总览 top 5 每行有 frequency evidence 与 source URL
5. 若做视频：≥3 个钩子；逐镜表 ≥7 列（scene、visual、narration、camera、lighting、sfx、duration、source_reference）
6. `visual-style-guide.xlsx` 含四个指定 sheet
7. 每个 sheet 的 source 列非空率 ≥95%
8. 终稿无未解释占位文本
9. 点名渠道均给出 format 与 style recommendation
10. 教学支架原文零出现
