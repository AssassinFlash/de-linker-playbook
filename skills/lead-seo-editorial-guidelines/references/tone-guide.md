# 语气选型参考

条件：选定或否决某一语气、写组合、或组装 Guidelines 块时读本文。执行顺序与完成条件以 `SKILL.md` 为准。

## 核心规则：最多 2 个语气

最多用 2 个 Tone。多了指令互相打架，输出不稳定。

## 推荐语气（稳定档）

多次跑下来可预期的档。B2B 获客文章优先从这里选。

| Tone | 效果 | 适合 |
| --- | --- | --- |
| Down-to-earth | 接地气、不端着 | 技术产品、制造与规格向 |
| Straightforward | 直说、不绕 | How-to、对比、采购指南 |
| Authentic | 自然、不演 | 合作故事、案例（案例须有来源） |
| Warm | 友善、不谄 | 对客说明、关系向内容 |

## 默认不要（SEO 文章）

| Tone | 问题 | 细节 |
| --- | --- | --- |
| Professional | 可读性差 | high-register：aim to、elevate、crucial；学术腔、过正式 |
| Witty | 过火 | 夸张，不像正常交流 |
| Humorous | 不稳 | 不像人口语，扫读变差 |
| Approachable | 方差大 | 有时可以，有时过分亲热 |

## 有条件才用

### Conversational

偶发自然。偶发非常浮夸。写入规范时必须要求成稿后人工复看。

### Write in the style of [Person]

方差大。不要当作默认指令。面客英文不稳时尤其不要用。

## 推荐组合

面向 B2B 出口/制造内容时，优先这些二选组合，仍不得超过 2 个：

| 组合 | 场景 |
| --- | --- |
| Down-to-earth + Straightforward | 技术产品文、选购指南 |
| Authentic + Warm | 公司故事、合作向（事实须有来源） |
| Straightforward + Authentic | How-to、行业分析 |

产品上下文已锁定的品牌语气与上表冲突时，记下冲突与取舍，不悄悄覆盖。

### 组装块形状

下游成稿指令要的是英文整段规则，不是中文策略。形状如下（语气与可读性须按当次产品上下文重写，禁止原样粘贴）：

```
Tone: Write in a down-to-earth, straightforward tone.
Reading Level: Write so a non-specialist buyer can scan once. Prefer short sentences and common words for complex specs; define jargon on first use.
Avoid: Being too salesy, getting too hyped, being robotic and repetitive, using cliche or formula language, using exclamations, using worst humor.
Text Format: Write in short paragraphs; use a single-sentence paragraph from time to time; use bullet points when they help scanning; vary sentence length.
Tips: Define new terms. Use "you" for the reader and "we" for the company. Cite sources when making claims. Do not use stock AI phrases such as "game changer" or "let's dive in".
```
