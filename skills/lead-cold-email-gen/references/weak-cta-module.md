# 低压弱 CTA

条件：模式为 Low-Pressure 或 Both 时读本文。执行顺序与完成条件以 `SKILL.md` 为准。

CTA 必须接到正文的痛点或洞察，像自然下一步，而不是另加一句约会议。禁用「Would you be open to a call?」及同义句。

所承诺的材料必须是已有交付物，或本轮能立刻写出的短件。不能承诺未做的竞品拆解、未持有的基准或未核实的合规摘要。

## 格式 1：情境微要约

**何时：** 能点到对方一个具体工作流、流程或挑战。

**句式：** 点名该情境 + 提出一份小而具体的材料 + 说明不要求对方改系统或开会。

`Since [已核验工作流], want a [小交付物] showing how [同类角色] [结果] — without [常见代价]?`

**为何：** 承诺低、感知价值具体。对方得到材料，不必答应销售通话。

## 格式 2：好奇心

**何时：** 确有可分享的对照、基准或时点变化，且来源已在「来源」表。

**句式：** 点名那份已有材料 + 邀请看一眼，不夸大。

`Just finished [有来源的对照或基准]. Want a quick peek?`

对照对象必须来自 `deliverables/lead/04-market/` 或本轮已抓取页。禁止虚构「对你们两家竞品做了基准」。无来源百分比不写进 CTA。

**为何：** 回信门槛是「发来看看」，不是权衡是否开会。

## 格式 3：买家阶段多选项

**何时：** 不确定对方处在评估、比选还是已在列供应商。

**句式：** 2–3 个不同承诺量的选项，让对方自选。

`Happy to send [低承诺材料] if you're still evaluating — or [中承诺材料] if you're already mapping vendors.`

选项必须都是本轮能交付的。任意一个选择都算回复。

**为何：** 把是/否开会换成三选一的低摩擦动作。

## 格式 4：破格

**何时：** 收件人冷信很多、模式识别强（资深采购、VP）。

**句式：** 打破「约会议」预期，用一个不卖产品的具体邀请。仍须可兑现，不用无来源的战胜百分比或对赌数字。

`Most [角色] ask us about price first. The ones who stay ask about [出乎意料但真实的因素]. Which camp are you in?`

**为何：** 打断自动删除。不可兑现的机智句不要用。

## 结构四式

同一批次里轮换，不要五封同一骨架：

1. **Pain → Fix → CTA** — 问题 → 一条 USP → 下一步
2. **Trigger → Insight → Micro-offer** — 已核验事件 → 含义 → 相关短件
3. **Stat → Reframe → Specific help** — 有来源的数字 → 含义翻面 → 针对性帮助；没有数字就改用第 1 式
4. **Micro-story → Takeaway → CTA** — 产品上下文或已抓取案例里的短故事 → 教训 → 对应要约；无案例不编

## A/B

每封可测三条轴，各写进主题 A/B 或 Performance Notes，不要另造一封假信凑数：

- 主题：洞察 vs 好奇
- CTA 力度：直接请求 vs 暗示价值
- CTA 语序：先要约 vs 先问句

## 收束句式

只用在语气需要收一下时，一句，不堆：

- 说一声就发
- 不急，觉得可能有用
- 发了也无附加条件
