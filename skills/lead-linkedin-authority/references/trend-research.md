# 趋势查证

条件：步骤「选题与查证」时读本文。默认用网页搜索查证；需要原文时抓取指定 URL 的正文。搜索不可用 → 停止并写缺口，不编造。日志格式不在本文重复。

花括号是字段，取产品上下文、已批准 ICP / 话题研究或用户本轮，不把花括号抄进交付物。`{year}` 用本轮日期的公历年。

## 三条意图

每条意图至少留下一行**有用**日志（能支持选用或否决该趋势）。某意图无有用结果 → 换查询或放弃该趋势，不拿噪声行凑数，不改搜其他引擎菜单。

1. **识别**  
   在品类与目标市场里找出一条宏观趋势（结构、需求、材料或工艺偏好、区域展望、供应侧含义）。

2. **核验**  
   确认该趋势真实、当前，并给将写入帖子的数字找来源。

3. **受众影响**  
   查这条趋势对该 ICP 所在行业与区域意味着什么。

## 查询模板

识别：

```
"{product_niche}" industry trend {target_market} {year}
latest trends in {product_niche} relevant to {target_market} buyers
```

核验：

```
"{identified_trend}" statistics data {year}
"{identified_trend}" "{product_niche}" market impact
```

受众影响：

```
"{identified_trend}" impact on {target_audience_industry} {target_market}
```

需要原文时，对拟引用页抓取正文，记下摘录。列表页、内容农场、无法指向具体主张的综述，记为噪声，不引用。

## 时效与选用

- 窗口：近 1–2 年的趋势、数据或公开展望。更早的材料只有被更新数据重新证实才可用。
- 搜不到、来源互斥到无法落笔、或只有无年份的泛论 → 不用该趋势，改核话题研究里的下一条，或停并写缺口。
- 帖中每一条统计必须能指回来源表的一行。没有来源的数字不写，改用已核验的定性观察，或不开数字钩子。
