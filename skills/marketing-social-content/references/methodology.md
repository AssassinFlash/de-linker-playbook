# 社媒内容方法

读本文件前先确认 `SKILL.md` 已判定本 skill 适用。此处是查询意图、数据门、分平台清单、表结构与附件规格。

目录：

- [收集](#收集)
- [分析](#分析)
- [交付](#交付)
- [缺口](#缺口)

品类、目标市场、产地、展会名称一律取产品上下文对应字段，不在本文件填值。

## 收集

### 查询意图

用网页搜索查证，覆盖下列意图；每条记下 URL、访问日期、摘录。证据够用或已写缺口即可停，不并列多家搜索引擎。

1. 具名竞品 + 公开公司页或 LinkedIn 公司帖（至少 3 家竞品帖、1 家本方主页若上下文有 URL）
2. 具名竞品 + Instagram / Facebook / TikTok / YouTube 账号或作品
3. 品类 + manufacturing process / factory tour 短视频格式与观看信号
4. 品类 + LinkedIn content strategy manufacturing export
5. 品类 + Instagram B2B engagement
6. 品类 + social media benchmarks / posting frequency
7. B2B manufacturing social media + 目标市场
8. 品类 + hashtag 或标签相关性（按拟用平台核体积与相关，不假设）
9. 目标买家角色 + 常用平台证据
10. 品类 + thought leadership / project showcase 高互动主题

### 抓取

需要原文时抓取指定 URL 的正文。优先：

- 竞品公司页、关于页、案例页上的社媒入口
- 可打开的公开帖、简介、精选视频说明
- 本方站点页脚或联系页上的社媒入口（上下文给出 URL 时）
- 平台官方帮助中心里的尺寸、时长、字数上限

用户已配置网页采集服务时，才用它抓公开页或动态页。未配置则只记录已搜到或已抓到的 URL。搜索或抓取不可用：停止并写缺口，不编造。

### 数据下限

硬门（达不到就写缺口，不降格成猜测）：

- ≥20 条竞品公开帖：格式、主题、钩子、互动信号、`source`
- ≥5 个竞品账号，覆盖 ≥3 个平台：粉丝或关注量、发帖频率、内容组合、`source`
- 发帖频率由实际时间戳计算，不凭印象
- 每条平台频率建议能指回一条基准来源

尽力项（有则写，无则缺口，不阻塞终稿）：

- 本方账号基线审计
- 单条行业标杆视频的时长与互动信号
- 标签体积核验
- 评论区是否出现买家语言（询盘、规格、到货）

### 核验

- 打不开的账号不进「已核验」名单。
- 互动率必须来自已采集帖，禁止用模型记忆里的「行业平均」。
- 标签建议必须核过相关或体积，否则标「未核验」且不进日历必发列。
- 每条对外基准有 URL 与访问日期。

## 分析

### 竞品审计字段

每家至少写：平台存在、粉丝、发帖频率与连贯性、高互动格式与主题、内容主题、评论/收藏/转发差异、询盘或 CTA 信号、来源。

### 分平台

**LinkedIn** — B2B 权威：主导格式、带动互动的主题、本行业公开账号的频率基准。

**Instagram** — 视觉陈列：短视频 / 轮播 / 单图在制造类账号上的相对表现；能触达进口商、承包商、设计师的标签组；快拍信号（有则记）。

**TikTok / Facebook / YouTube 短视频** — 触达与认知：流程片是现场原片还是精修片更有观看；评论是买家还是路人。

每条平台建议必须同时有：目标买家出现证据、推荐频率、格式优先级、漏斗阶段贡献。

### 内容支柱（默认起点）

按已采集表现改百分比，并引用来源。沿用下表必须写明「竞品样本未显示可辩护偏移」及样本范围。

| 支柱 | 默认占比 | 主题方向 |
| --- | --- | --- |
| 项目展示 | 30% | 已交付现场、前后对比、客户应用 |
| 生产过程 | 25% | 设备、质检、包装、物料、安全 |
| 教育 | 20% | 选材、规格对比、维护、如何写入询价 |
| 行业动态 | 15% | 市场变化、展会（仅上下文已列名称）、新品 |
| 幕后 | 10% | 团队、原料、出货准备 |

### 钩子类型

从已采集帖里统计哪类钩子互动更高，再用于模板，不把本表当可粘贴文案：

1. 项目结果：数量 + 地点 + 交付回顾
2. 过程好奇：这类产品实际怎么做
3. 教育对比：规格 A 与规格 B 的可观察差别
4. 反常识：低价与总拥有成本
5. 社会证据：已发运市场数 + 目标市场最常下的配置（仅上下文或已核来源有数字时）

### 二次分发

一条原始素材至少衍生 3 条平台原生帖。对照：

| 原始素材 | 可衍生 |
| --- | --- |
| 完工项目照片 | 轮播 + LinkedIn 案例文 + 目标渠道（以产品上下文为准）更新 |
| 工厂流程视频 | 15–30 秒短视频 + 短视频平台再剪 + LinkedIn 教育帖 |
| 质检镜头 | LinkedIn 信任帖 + 相册 |
| 包装装柜 | 快拍或即时通讯状态（仅目标市场在用时） |

## 交付

### 工作簿列

从 `templates/social-calendar.xlsx` 复制后填。JSON 与表字段一致。

**Social Calendar**（≥30 行）：`week`, `date`, `platform`, `content_type`, `topic`, `copy_draft`, `visual_notes`, `hashtags`, `cta`, `status`, `source`。`copy_draft`、`visual_notes`、`hashtags`、`cta`、`source` 禁止空。

**Competitor Social Audit**（≥5 行）：`competitor`, `platform`, `followers`, `post_frequency`, `avg_engagement`, `top_post_type`, `content_themes`, `source_url`。`followers`、`post_frequency`、`top_post_type` 禁止空。

**Post Templates**（≥10 行）：`template_name`, `platform`, `format`, `hook`, `body_structure`, `cta`, `best_time`, `hashtags`, `source`。`hook`、`body_structure`、`cta` 禁止空。

日历覆盖 ≥3 个不同平台。`date` 必须是日历日。

### 执行附件

与 `index.md` 同目录：

- `posting-calendar.md`：4 周，每天写平台、内容类型、时间、标签、来源
- `post-drafts.md`：10–20 条，按平台分组，文案 + 视觉方向 + 来源
- `hashtag-strategy.md`：分平台的行业 / 产品 / 长尾组合，带来源
- `content-pillars.md`：3–5 个方向；形状用结构说明，不粘贴 skill 例子
- `platform-specs.md`：图片尺寸、视频时长、字符限制、时段；全部来自已核官方说明，过期数字不背

### 漏斗对齐

| 阶段 | 看的信号 | 更匹配的内容 |
| --- | --- | --- |
| 访问 | 曝光、触达、来自目标市场的主页访问 | 流程短视频、项目展示、教育轮播 |
| 询盘 | 买家语言私信、目标渠道询价波动、链接点击 | 带规格的案例、能力帖 |
| 样品 | 样品请求、目录下载 | 表面/细节对比、特写 |
| 订单 | 能追到成交的社媒询盘 | 交付可靠性证据 |
| 复购 | 老客户再互动、项目共标 | 客户现场、新品 |

### 展会节点

若产品上下文列出展会或行业活动：在日历上安排预热、现场、复盘三截内容，日期核官方源。上下文没有展会则本节写「不适用」，不发明场次。

## 缺口

- 竞品互动未知：只用已搜索到的行业基准区间，标明「行业基准」，并建议对具体账号补一次采集。
- 平台基准缺失：显式列缺口；建议 4 周基线追踪后再优化频率。
- 找不到竞品社媒：记下「该利基公开社媒稀疏」及来源，当作机会而不是编造对手账号。
- 本方无账号或无素材清单：日历仍可按竞品证据写，但把账号建设与拍摄清单标为 P0，不假装已有素材。
