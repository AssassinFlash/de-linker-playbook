# 价值映射框架

条件：定向客户调研做到价值映射步时读本文。六维按**这家公司**取舍，不是每维都要有故事。完成条件以 `SKILL.md` 为准。

## 映射维

### 1. Operational Fit

- 看：其经营里有没有直接用到这类产品。
- 证据：产品页、运营相关招聘、工厂或设施新闻。
- 问：哪条具体能力减轻其哪道具体工序的摩擦。
- 强信号：已在用竞品同类产品。
- 弱信号：公开材料看不到该类产品进了其经营。

### 2. Strategic Alignment

- 看：其战略方向会不会产生新的采购需求。
- 证据：新闻稿、年报、管理层公开发言或公司帖。
- 问：哪条具体 USP 支撑其哪项已宣布的目标。
- 强信号：近期倡议直接需要这类产品。
- 弱信号：只有「创新」「增长」空话。

### 3. Pain Point Resolution

- 看：产品是否对准一条**已记录**的问题。
- 证据：客户投诉、召回或故障新闻、行业论坛。
- 问：哪条具体能力消掉其哪条具体痛点。
- 强信号：公开记录里就是产品所解的问题。
- 弱信号：按行业常识假定的痛点。

### 4. Cost / Efficiency

- 看：有没有对得上的成本或效率影响。
- 证据：财务披露、经营基准、竞品公开价。
- 问：产品上下文或已抓取页里，有没有对上其成本中心的数字。
- 强信号：可引用的数字与来源年份。
- 弱信号：只有「省钱」而无数据。无数字则写「未在来源出现」，不编 ROI。

### 5. Compliance / Certification

- 看：其采购是否要求我方已有的合规证明。
- 证据：行业法规、招标要求、证书目录。
- 问：产品上下文或已批准 USP 里的哪张证书对上其哪条要求。
- 强信号：受监管行业且要求写明。
- 弱信号：看不到具体合规需求。证书名不得发明。

### 6. Supply Chain

- 看：交期、产地、产能是否能加强其供应可靠性或多元性。
- 证据：供应商多元披露、中断新闻、 sourcing 策略。
- 问：产品上下文里已有的交期 / 产地 / 产能如何对上其供应缺口。
- 强信号：正在换商，或近期中断有公开记录。
- 弱信号：现有供应看起来稳定、无缺口。未在上下文出现的交期与产地不编。

## 评分

| Score | 含义 | 动作 |
| --- | --- | --- |
| Strong | 需求有直接证据，且产品对得上 | 外展主角度 |
| Moderate | 间接证据或合理推断 | 次要提及 |
| Weak | 无证据、仅行业上说得通 | 未再验证前不写入外展 |
| None | 找不到连接 | 不硬编 |

None 是合法完成，不是失败。按与该公司的相关度排序六维，不要等权。Weak 不进战略叙事主句；叙事只从 Strong 取，不够再取 Moderate。

```markdown
- primary_angles: （仅 Strong）
- secondary_angles: （Moderate）

```

`strength` 取值 `strong` / `moderate` / `weak` / `none`。`prospect_need` 必须带证据；`usp_match` 必须是已批准 USP 或产品上下文里的具体能力，不是「高质量」。

## 易错

1. 某维没有真实连接仍写成 Moderate 以上。
2. 用对任何买家都成立的 USP 去填表。
3. 只从卖方视角对齐，买方看不出为什么要在乎。
4. 对齐句没有六源里的 URL。
5. 六维平均用力，忽略该公司真正在意的一两维。
