## 用法

种子是动态提问的起点，不是固定问卷。按产品上下文和上游交付物已有的信息改写、跳过或合并。

**已在事实源入口 `docs/fact-sources.md` 所指的三方或 `deliverables/lead/` 上游文件里回答过的，不问。** 交付物只写用户确认的事实，不粘贴种子原句。

未出现在本文的 `lead-*` skill：读该 skill 的 `SKILL.md` 数据需求，按四维现场生成，不拿下面某张表硬套。

## lead-icp-analysis

焦点：应用场景、买家类型、市场细分。

| 维度 | 种子 |
| --- | --- |
| PMF | 产品主要用在哪些场景？不同场景的设计需求有差异吗？ |
| PMF | 核心竞争优势是什么？和竞品比，最突出的差异在哪？ |
| 范围 | 分析几条 ICP？是否有特定行业要排除？ |
| 范围 | 产品上下文里的目标市场是同时分析，还是先聚焦一个？ |
| 标准 | ICP 分析最重要的产出是痛点、策略，还是决策人？ |
| 标准 | 每条 ICP 要多细？概述级，还是细到能写冷邮件？ |
| 上游 | （入口节点，通常无上游问题） |

## lead-search-term-expansion

焦点：搜索平台、用词、每条 ICP 的范围。

| 维度 | 种子 |
| --- | --- |
| PMF | 目标公司通常怎么形容自己？行业场合里听过哪些自我定位？ |
| 范围 | 搜索词主要用在哪个平台？通用网页、职业网络、行业名录，还是全覆盖？ |
| 范围 | 术语风格更偏专业词还是口语？ |
| 标准 | 每条 ICP 要多少搜索词？ |
| 标准 | 验证标准是必须有搜索量，还是定位准确即可？ |
| 上游 | 已有 ICP 是否全部生成搜索词，还是只做优先的？ |

## lead-company-research

焦点：选公司标准、信息深度、模式。

| 维度 | 种子 |
| --- | --- |
| PMF | 理想目标公司是什么样？有没有已知标杆可以对照？ |
| PMF | 目标是直接终端用户，还是中间渠道？ |
| 范围 | 用该 skill 的标准模式还是新兴模式？员工数有没有上下限？ |
| 范围 | 地域：产品上下文里的市场全部覆盖，还是先聚焦一个？ |
| 标准 | 最看重哪类信息？域名、采购行为，还是决策流程？ |
| 标准 | 公司数量目标是多少？ |
| 上游 | 搜索词表里哪些类别先用？ |

## lead-distributor-research

焦点：分销商画像、合作标准、区域。

| 维度 | 种子 |
| --- | --- |
| PMF | 理想分销伙伴是什么样？已有仓库、有终端客户，还是有行业口碑？ |
| 范围 | 分销商规模有没有上下限？ |
| 范围 | 是否排除已经代理竞品的分销商？ |
| 标准 | 该 skill 列出的分析维度里，哪几个最重要？合作潜力、供应链可靠性，还是客户评价？ |
| 上游 | 是否基于已有公司名单扩展分销商搜索？ |

## lead-retailer-research

焦点：零售细分、品牌位置、利基。

| 维度 | 种子 |
| --- | --- |
| PMF | 目标零售商卖成品、做定制，还是两条都要？对照产品上下文的渠道类型。 |
| 范围 | 员工数上限？只看线上，还是也包括实体店？ |
| 标准 | 最看重零售商的哪个特征？市场地位、客群，还是采购频率？ |
| 上游 | 搜索词里哪些类别最适合发现零售商？ |

## lead-contact-discovery

焦点：职位、渠道优先级、数据质量。

| 维度 | 种子 |
| --- | --- |
| PMF | 最想联系的决策人是什么职位？采购、设计负责人，还是一把手？ |
| 范围 | 每家公司找几人？是否只找特定部门？ |
| 范围 | 是否使用已配置的联系人发现服务做批量搜索？未配置则只走公开Apify 搜索，联系人标待补。 |
| 标准 | 联系人最低要求：必须有邮箱，还是职业网络主页即可？ |
| 标准 | 单源信息是否接受，还是必须交叉验证？ |
| 上游 | 从哪些公司名单采集？全部还是优先某些 ICP？ |

## lead-competitor-analysis

焦点：竞品范围、定位深度、空白优先级。

| 维度 | 种子 |
| --- | --- |
| PMF | 已知主要竞品有哪些？来自原产国厂商，还是目标市场本地厂商？ |
| PMF | 竞品分析是为了定价参考、差异化定位，还是销售话术？ |
| 范围 | 分析多少种定位策略？每种几家代表公司？ |
| 标准 | 市场空白要多深？列出机会即可，还是要具体行动建议？ |
| 上游 | 是否按 ICP 痛点反看竞品覆盖？ |

## lead-market-analysis

焦点：分析深度、数据新旧、战略重点。

| 维度 | 种子 |
| --- | --- |
| PMF | 市场分析主要给谁用？内部决策、投资人，还是销售支持？ |
| 范围 | 该 skill 列出的板块是全部做，还是只做某几块？ |
| 范围 | 数据年份：只要最近两年，还是更早的也可以？ |
| 标准 | 增长率与市场规模要几个来源交叉验证？ |
| 标准 | 建议要多具体？方向级，还是带时间线的行动？ |
| 上游 | 竞品分析里哪些发现要在市场分析里加深？ |
